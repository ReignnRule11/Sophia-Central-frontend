# Sophia Central Frontend

A modern React + Vite + TypeScript + Tailwind MVP for Sophia Central, designed as a production-ready operations dashboard and command center.

## Features

- Secure auth shell with protected routes
- Executive dashboard with KPI cards and system health monitoring
- Project pipeline and team capacity views
- Insight and opportunity tracking
- Responsive, dark-mode-first UI system
- Modular app architecture for scale

## Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- React Router
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open the local app at http://localhost:3000.

## Build

```bash
npm run build
```
